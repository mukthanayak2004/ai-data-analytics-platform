# AI Data Analytics Platform

An interactive AI-based data analytics platform designed to simplify data exploration, visualization, and analysis.

## Features

* CSV Dataset Upload
* Dataset Preview
* Statistical Analysis
* Interactive Data Visualization
* Data Insights
* Responsive Dashboard

## Technologies Used

* React.js
* JavaScript
* CSS
* Python
* Streamlit
* Pandas
* Plotly
* Recharts
